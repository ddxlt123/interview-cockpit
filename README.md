# 面试舱

本地运行的模拟面试 Web 应用。内置题库来自飞书文档《七大方法论面试题库与参考作答》，共 70 道题。

在线地址：[https://ddxlt123.github.io/interview-cockpit/](https://ddxlt123.github.io/interview-cockpit/)

## 功能

- 每轮随机打乱题目，点击“下一题”切换。
- 题库页浏览全部题目，支持关键词搜索、分类筛选，并可从任意题目开始练习。
- “方法论速查”按五个领域收录飞书原文中的 36 个方法论，可切换概要、详情或隐藏内容。
- “STAR 合集”收录 7 条个人项目经历，可查看行动链概要或完整 S/T/A/R 内容，每条附带 3 个针对性面试追问。
- 分别查看回答提示或完整参考作答。
- 导入 `.docx`、`.md`、`.txt`、`.json` 题库。
- 将当前题目、分类、考察点、提示和参考作答导出为 PNG 答题卡。
- 收藏题目并按“未评估 / 生疏 / 练习中 / 熟练”记录自评，题库支持对应筛选。
- 登录同一邮箱后，在电脑和手机间自动同步收藏与熟练度；断网操作会在恢复网络后合并。
- 将学习进度导出为 JSON，或导入另一台设备的 JSON 并自动合并，作为手动备份方案。
- 导入题库保存在浏览器 `localStorage`，不上传服务器。
- 支持安装到手机桌面；首次联网打开后，内置题库、方法论和 STAR 合集可离线使用。

## 运行

```bash
npm install
npm run dev
```

构建与测试：

```bash
npm test
npm run build
```

跨设备自动同步需要一次性配置 Supabase，详见 [SUPABASE_SYNC_SETUP.md](./SUPABASE_SYNC_SETUP.md)。未配置时，应用仍会完整保留本地进度和 JSON 导入/导出功能。

## 安装到手机

部署到 HTTPS 地址后，先联网打开一次：

- iPhone：用 Safari 打开，点击“分享” → “添加到主屏幕”。
- Android：用 Chrome 打开，点击菜单 → “安装应用”或“添加到主屏幕”。

安装完成后，即使没有网络，也能打开内置的 70 道题、36 个方法论和 7 条 STAR 经历。用户后来导入的题库只保存在导入设备的浏览器中，不会自动同步到其他设备。

## 文档格式

参考 `题库模板.md`。每道题使用以下字段，题目之间直接换行：

```text
题目：...
分类：...
考察点：...
提示：提示一；提示二；提示三
参考作答：...
```

`提示` 可省略，应用会从参考作答的前两句话中提炼 1—3 条提示。JSON 支持字段：`question`、`hints`（数组）、`answer`、`category`、`topic`。
